# Password Strength Checker

## Overview

This project checks the strength of a user's password.

## Features

- Checks password length
- Detects uppercase letters
- Detects lowercase letters
- Detects numbers
- Detects symbols
- Classifies password as:
  - Weak
  - Medium
  - Strong

## Technologies

- Python 3

## How to Run

```bash
python app.py
```
