# Phishing Red-Flag Checklist (Non-Expert Edition)

A quick, no-jargon checklist any employee can run through in under a minute.
If **any** box is checked, treat the message as suspicious and move to the
[decision tree](decision-tree.md).

## 1. The Sender
- [ ] The display name (e.g. "PayPal Support") doesn't match the actual email address when you hover/tap it.
- [ ] The domain is *almost* right but not quite (`paypa1.com`, `micr0soft-support.com`, `amaz0n-gifts.com`).
- [ ] The domain has extra words bolted on (`accounts-google-secure.com`, `yourcompany-secure-login.com`).
- [ ] A "CEO" or "IT Security" message comes from a free email provider (Gmail, Yahoo, Outlook.com).

## 2. The Tone
- [ ] Creates urgency ("act within 24 hours", "account will be disabled", "30 minutes").
- [ ] Promises something too good to be true (prize, free gift, unexpected refund).
- [ ] Threatens a consequence (legal action, account termination, job loss).
- [ ] Asks you to keep the request secret or skip normal approval steps.

## 3. The Links & Attachments
- [ ] Link text says one thing but the real destination (hover to preview) is different.
- [ ] Link uses `http://` instead of `https://`.
- [ ] Link is a shortened URL (`bit.ly`, `tinyurl.com`, etc.) hiding the real destination.
- [ ] Link points to a raw IP address instead of a website name.
- [ ] Attachment has an unusual extension (`.exe`, `.scr`, `.js`, `.iso`, `.hta`).
- [ ] A QR code is used instead of a normal link (pushes you to your less-protected phone).

## 4. The Ask
- [ ] Requests a password, MFA code, or one-time passcode.
- [ ] Requests bank details, a wire transfer, or a change to payment information.
- [ ] Requests personal information "to verify your account."
- [ ] Asks you to call a phone number instead of visiting a known website (callback / TOAD scam).

## 5. The Golden Rule
> **PAUSE. VERIFY. REPORT.**
> 1. **Pause** — don't click, reply, or call the number in the message.
> 2. **Verify** — contact the sender through a channel *you* already trust (a known phone number, a fresh browser tab, walking over to their desk). Never use contact info from the suspicious message itself.
> 3. **Report** — forward it to the security team / use the "Report Phishing" button. Do not just delete it — reporting lets the team purge the same message from everyone else's inbox.
